# بروفة الحج · Hajj Rehearsal

امشِ رحلة الحج على الخريطة الحقيقية للمشاعر قبل ما تسافر: منى، عرفات، مزدلفة، جمرة العقبة، أيام التشريق، وطواف الوداع. فيها تسع لغات: العربية، English، اردو، Bahasa Indonesia، বাংলা، Türkçe، فارسی، Hausa، Français.

**جرّبها:** https://hosam382.github.io/hajj-rehearsal/

- الأرض من صور أقمار صناعية حقيقية (Esri World Imagery) فوق تضاريس حقيقية (AWS Terrain Tiles)، والصور أدق في منى وعرفات ومزدلفة والحرم.
- رقم مخيم الحاج يظهر على الخريطة.
- كل محطة فيها وقتها في اليوم، وشرح مختصر، ونصيحة.
- المسار تقريبي وهدفه التعريف. للفتوى ارجع إلى «نسك AI» أو المرشد الشرعي في حملتك.

نموذج تجريبي · فكرة وتنفيذ **حسام حسين بخش**

صور الأقمار الصناعية: Esri, Maxar, Earthstar Geographics · التضاريس: AWS Terrain Tiles · Three.js
